    🤖 AI API 키 설정

    🖥️ 로컬 프로그램 실행 브릿지

    메모에 로컬 파일·폴더·프로그램 경로를 넣어두면 Windows 연결 프로그램으로 바로 실행합니다.
    사용 전 local-bridge/로컬연결_실행.bat 파일을 더블클릭해 켜두세요.

    💾 세컨드 브레인 데이터 백업 / 복원

    다른 기기나 브라우저로 옮길 때 JSON 파일로 내보내거나 불러올 수 있습니다. (API 키는 백업 파일에 포함되지 않습니다)

    🔥 Firebase Google 인증 (로컬 항목 보호)

    🔒 잠김 상태
    허용된 내 구글 계정으로 로그인해야 저장한 로컬 항목을 보고 실행할 수 있습니다.
    ⚠️ Firebase Google 로그인은 file:// 주소에서 동작하지 않습니다.
    local-bridge/로컬연결_실행.bat을 실행해 http://localhost:4820으로 열거나 GitHub Pages에서 접속해 주세요.

    🔥 Firebase 설정

    📖 1분 만에 Firebase Google 로그인 설정 방법 보기
    1. Firebase 콘솔에서 프로젝트 생성 → 좌측 빌드 → Authentication → 시작하기
    2. 로그인 방법(Sign-in method)에서 Google 선택 → 사용 설정 ON → 저장
    3. 프로젝트 설정(⚙️) → 내 앱 → 웹 앱(</>) 추가 → 나오는 firebaseConfig를 복사해 위 칸에 그대로 붙여넣고 저장
    4. GitHub Pages 사용 시: Authentication → 설정 → 승인된 도메인에 내아이디.github.io 추가 (localhost는 기본 허용됨)
    5. local-bridge/bridge-config.json에도 firebaseApiKey, firebaseAuthDomain, firebaseProjectId, allowedEmail을 입력하면 PC 브릿지에서도 이중 검증됩니다.
