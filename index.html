      ☁️ Google 로그인 & Drive 동기화

      🔒 잠김 상태
      내 구글 계정으로 로그인하면 내 드라이브(SecondBrainOS 폴더)에 메모·HTML·MD·이미지·PDF·PPT가 자동 동기화됩니다.
      ⚠️ Google 로그인은 file:// 주소에서 동작하지 않습니다.
      local-bridge/로컬연결_실행.bat을 실행해 http://localhost:4820으로 열거나 GitHub Pages에서 접속해 주세요.

      Firebase 설정 (본인 프로젝트 직접 입력)

      📖 Firebase 로그인 & Google Drive API 설정 방법 (2분)
      1. Firebase 콘솔에서 프로젝트 생성 → 좌측 빌드 → Authentication → 시작하기
      2. 로그인 방법(Sign-in method)에서 Google 선택 → 사용 설정 ON → 저장
      3. 프로젝트 설정(⚙️) → 내 앱 → 웹 앱(</>) 추가 → 나오는 firebaseConfig를 복사해 위 칸에 붙여넣고 저장
      4. [Google Drive 동기화 활성화] Google Cloud 콘솔 (Drive API)에서 위와 같은 Firebase 프로젝트를 선택한 뒤 사용(Enable) 클릭
      5. [OAuth 테스트 사용자 등록] Google Cloud 콘솔 → API 및 서비스 → OAuth 동의 화면 → 대상(Audience)에서 본인 구글 이메일을 테스트 사용자로 추가
      6. GitHub Pages 사용 시: Firebase Authentication → 설정 → 승인된 도메인에 내아이디.github.io 추가 (localhost는 기본 허용)
